 1. presentation du projet cantine
le projet cantine est un projet qui permet de gerer les commandes dans une cantine.
il permet de calculer le total à payer en fonctoin du plat choisi et de la quantite commandee.
calcler le montant de la monnaie à rendre ou le montant manquant si le client n'a pas assez d'argent pour payer sa commande.

 2.menu de la cantine 
attieke -poisson : 1500 FCFA
riz-poulet : 2000 FCFA
alloco-œuf : 1000 FCFA

 3.fonctionnement du projet :
1. le client choisit un plat en entrant le code correspondant.
2. le client entre la quantite souhaitee.
3. le client entre le montant qu'il souhaite verser.
4. le programme calcule le total a payer et affiche les details de la commande.
5. si le montant verse est suffisant, le programme calcule la monnaie a rendre.
6. si le montant verse est insuffisant, le programme calcule le montant manquant et l'affiche. 

  4.execution du programme :    
pour executer le programme, il suffit de lancer le fichier cantine.js dans un terminal 
ou un environnement de developpement compatible avec Node.js. Le programme affichera les details de la commande
 et les calculs effectues en fonction des entrees du client.

 5.test du projet :
pour tester le projet, vous pouvez modifier les valeurs des variables client, codePlat, quantite et montantVerse dans le fichier cantine.js.
ensuite, executez le programme pour voir les resultats en fonction des nouvelles entrees.
